# Project playbooks

Project memory lives outside this skill, in two parts:
- **Series lock** (`series-lock.md`): the approved look; the working copy in project files.
- **Playbook**: research that outlives a series (reference slate, style research, period
  and place notes, clichés, open decisions). A playbook skill (triggers on the project's
  name or subject), project markdown, or a Claude Doc.

At intake and research, look for both (installed skills naming the project, genre or period;
project files; any bible the user mentions). Settled playbook decisions outrank fresh ideas
unless the user asks; findings keep their evidence tags.

## Format (sections or files)

1. **Genre**: fingerprint pattern; reference slate (film, lane, take, don't copy, evidence);
   principles → decisions; set-piece types; clichés; sound.
2. **Style research**: technique table and directions (`art-department.md` §1).
3. **Period and place**: real light sources, places and outlines, lettering and type
   families, sound world, history to respect, what to avoid.
4. **Project decisions**: originality boundary; settled and open decisions.
5. **Lock**: latest approved lock and version history.

When a session adds to a playbook, give the user the updated section to save.
